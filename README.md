# MarketHub

Panel sencillo de precios de criptomonedas con alertas.

## Qué hace

- Muestra las treinta criptomonedas con más capitalización: precio, variación de veinticuatro horas, capitalización y volumen.
- Se actualiza sola cada minuto. Puedes elegir euros o dólares y buscar una moneda por nombre.
- Alertas de precio: eliges una moneda, si quieres el aviso cuando suba por encima o baje por debajo de un precio, y la página te avisa en pantalla (con un pitido y, si lo permites, con un aviso del sistema).
- Las alertas se guardan en tu navegador. Solo funcionan mientras la página esté abierta.

Los datos vienen de la API pública y gratuita de CoinGecko. No hace falta ninguna clave.

## Cómo verla

Opción rápida: descarga los archivos y abre `index.html` con doble clic.

Publicarla en internet con GitHub Pages:

1. En el repositorio, entra en **Settings**, luego **Pages**.
2. En "Source" elige **Deploy from a branch**, rama **main**, carpeta **/ (root)** y pulsa **Save**.
3. En uno o dos minutos estará en `https://chumito78.github.io/markethub/`.

Solo información. No es asesoramiento financiero.
